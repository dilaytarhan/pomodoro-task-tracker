## Features

- ⏱️ Customizable Pomodoro timer (focus, short break, long break)
- 📝 Task management with priority levels
- 📊 Track focus time, sessions, and completed tasks
- 🌙 Dark/Light theme toggle
- 🔊 Sound notifications for timer completion
- ⌨️ Keyboard shortcuts (Space = start/pause, R = reset)
- 💾 Everything saved locally in your browser
- 📱 Works on desktop and mobile

## Quick Start

**No installation needed!**

1. Open the [Live Demo](https://dilaytarhan.github.io/pomodoro-task-tracker/)
2. Or download and open `index.html` in your browser
3. Click play (or press Space) to start

## How to Use

**Timer Modes:**
- **Focus** - 25 minutes of work
- **Short Break** - 5 minute break
- **Long Break** - 15 minute break after 4 sessions

**Tasks:**
- Add tasks with priority (Low/Medium/High)
- Click task to focus on it
- Check off when done
- Filter by All, Active, or Done

**Settings:**
- Customize timer durations
- Enable/disable sound and notifications
- Auto-start breaks and focus
- Reset daily stats

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space | Start / Pause |
| R | Reset |
| Enter | Add task |

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- No frameworks or dependencies
- Uses browser localStorage
- Web Audio API for sounds

## Troubleshooting

**Sounds not working?**
- Enable "Sound alerts" in Settings ⚙️
- Check browser console (F12) for errors

**Data not saving?**
- Clear browser cache and reload
- Check if localStorage is enabled

**Timer frozen?**
- Refresh the page
- Try a different browser
